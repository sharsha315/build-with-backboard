# Teach You Assistant

## What is RAG?
RAG stands for Retrieval Augmented Generation. In plain terms, it means giving your AI assistant access to real documents so it can answer questions based on actual content rather than just its training data. Instead of guessing, your assistant retrieves the elevant information from your files and generates an accurate response. Backboard handles all the complexity (indexing, searching, embedding) automatically. You just upload a file and start asking questions.

## Demo Overview
In this demo, we upload a document to your assistant and ask it questions about the contents. Backboard automatically indexes and makes your document searchable, so your assistant can respond with answers grounded in real data.

## Upload a PDF Document and Ask a Question
1. Upload a PDF document, for this demo project, upload PDF in the `teach_your_assistant` folder.
2. Name the PDF document as `my_document.pdf`.
3. Run the script,
``` python teach_your_assistant/main.py```
